#### 📝 Notes
- Of course, the first step is import library by `from tkinter import *`
- we are should to create variable for every window in the app and use it 
    - `app-window = Tk()`
- after that to we can summon something method directly (Related to the window):
```python
app-window.title("this is window title')
app-window.geometry("1000×500") # height and width of window
```
- now for add some content to this window we are sure to do that:
- for add text label (just text), which is
    - `text-label = Label(app-window, text = "the text")` 
    - now we are have label text but it doesn't appear in the window because we are should to set it in the window that's by: 
        - `text-label.pack()`
- for add input:
    - `input-label = Entery(app-window, textvariable = var-want-to-set-input-text-value-in-it)`
    -  as always: after var
        - `input-label.pack()`

- now we can do anything on the `var-want-to-set-input-text-value-in-it` like change of var type to integer or check of it value by normal python codes, and they appear the result by add label for it 
- Simply put, the library's sole purpose is to display results. As programmers, we typically use consoles a lot, but something we are need to see our work in the window just that.
