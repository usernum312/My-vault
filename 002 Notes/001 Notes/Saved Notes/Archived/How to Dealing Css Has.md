المشكلة التي تواجهك شائعة جداً عند التعامل مع المحدد :has() والتضمينات (embeds) في برنامج اوبسيديان (Obsidian).
بما أن التضمين يضيف عناصر جديدة تحتوي على نفس الكلاسات (مثل العناوين أو اتجاه النص)، فإن المحدّد :has() يبدأ بـ "التحسس" لوجود هذه الكلاسات داخل التضمين، فيقوم بتطبيق الستايل على الصفحة الرئيسية كلها حتى لو لم تكن الصفحة الرئيسية تحتوي على هذه الكلاسات فعلياً.
الحل يكمن في **عزل التضمينات** ومنع المحدّد من البحث بداخلها، أو التأكد من أن الكلاسات المستهدفة هي **أبناء مباشرين** أو تابعة لجسد الصفحة الرئيسية فقط وليس بداخل حاوية التضمين (.markdown-embed).
إليك أفضل الطرق لحل هذه المشكلة:
### الحل الأول: استبعاد التضمينات باستخدام :not()
يمكنك تعديل الكود ليتحقق من وجود الكلاسات المطلوبة، بشرط ألا تكون هذه الكلاسات داخل حاوية التضمين .markdown-embed. نقوم بذلك عبر دمج المحدّد العكسي:
```css
/* يطبق الستايل إذا كانت الصفحة تحتوي على الكلاسات بشرط ألا تكون داخل embed */
:root:has((.inline-title-is-rtl, .center-everything, .rtl-everything):not(.markdown-embed *)) {
    /* الستايل الخاص بك هنا */
}

```
### الحل الثاني: تحديد المسار المباشر لكلاسات الصفحة (الأكثر أماناً)
في اوبسيديان، العناصر الحقيقية للصفحة الحالية تكون عادةً داخل حاوية العرض الرئيسية (.markdown-view أو .markdown-rendered). يمكنك إجبار :has() على البحث فقط عن الكلاسات التي تنتمي مباشرة لعرض الصفحة وليس للتضمينات:
```css
/* البحث فقط داخل محتوى الصفحة الحالية وتجاهل التضمينات فرعياً */
:root:has(.markdown-readable-line-width > .inline-title-is-rtl, .center-everything, .rtl-everything) {
    /* الستايل الخاص بك هنا */
}

```
*ملاحظة: إذا كنت تستخدم الكلاسات .center-everything و .rtl-everything كـ Properties في الـ Frontmatter (أي يتم إضافتها لكلاسات الـ body أو .markdown-source-view)، يفضل كتابتها هكذا:*
```css
:root:has(.markdown-source-view.rtl-everything, .markdown-rendered.rtl-everything, .inline-title-is-rtl:not(.markdown-embed *)) {
    /* الستايل الخاص بك هنا */
}

```
### لماذا لم يعمل :is()؟
المحدد :is() لا يحل المشكلة لأنه مجرد أداة لاختصار الكتابة وتقليل التكرار (Syntactic Sugar)، فهو لا يغير طريقة بحث المتصفح في شجرة العناصر (DOM)، وبالتالي سيظل يرى الكلاسات الموجودة داخل التضمين. أما :not(.markdown-embed *) فهي تخبر المتصفح صراحةً: *"إذا وجدت الكلاس داخل حاوية تضمين، فتجاهله ولا تحسبه"*.
جرّب **الحل الأول** فهو الأبسط والأسرع في حالتك، وأخبرني إذا استمرت المشكلة!
