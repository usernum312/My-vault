### Note About Ai Assistant plugin improvements
- When a problem prevents the user from sending the message, show an option "Resend".

- Since users can access settings via shortcuts, I don't see a need for a dedicated button solely for settings. I want to replace it with another button, using the `lucide-menu` icon.

- When this button on the side is pressed, a somewhat wide vertical panel will appear, occupying 60% of the sidebar's width. Inside it, there will be horizontal rows representing conversations. Each row will display the conversation's name. Pressing a row will navigate the user to that conversation; this action will be considered 'activate' action.

- To the left of the conversation name, there will be three dots. When these are pressed, the user will see the following options: change name, change role, duplicate, delete, save.
