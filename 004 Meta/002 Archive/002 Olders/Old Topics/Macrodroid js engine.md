### 1. مواصفات بيئة التشغيل (Environment)
 * **المحرك المستخدم:** JetPack JavascriptEngine (يعمل داخل بيئة أندرويد).
 * **إصدار التوافق:** يفضل استخدام معايير EcmaScript القديمة والمستقرة والمستقلة عن المتغيرات الحديثة مثل let أو const في بعض الحالات الصارمة، والاعتماد على var لتفادي أخطاء الـ *Strict Mode*.
### 2. القيود والمشاكل الشائعة
عند كتابة أي كود لهذه البيئة، يجب مراعاة الآتي بشكل صارم:
 * **منع الرموز التعبيرية المباشرة (No Regex Literals):** محرك التطبيق يفسر الرمز المائل الثنائي // على أنه تعليق حتى لو كان داخل علامات الاقتباس أو كود Regex (مثل /regex/g). **الحل:** بناء الرموز التعبيرية دائماً عبر الكائن النصي الآمن:
   ```javascript
   var reg = new RegExp('pattern', 'g'); 
   ```
 * **تأمين النصوص متعددة الأسطر:** عند استدعاء متغير من ماكرودرويد يحتوي على أسطر متعددة أو علامات اقتباس، يتم استخدام علامات الحصر الخلفية (Template Literals) لمنع كسر الكود:
   ```javascript
   var txt = `{lv=variable_name}`;
   ```
 * **مخرجات الدالة (Output):** البيئة لا تدعم return عادي في نهاية الملف، بل تعتمد حصراً على الدالة الخاصة بالتطبيق لتمرير البيانات للمتغيرات المستهدفة:
   ```javascript
   mdOutput(variable);
   ```
### 3. صيغة إرسال الطلب المستقبلي (Template)
عندما تحتاج كوداً جديداً، يمكنك صياغة طلبك بهذا الشكل المباشر لضمان الحصول على كود يعمل من المرة الأولى:
> **الطلب:** ...
> **معلومات البيئة المستهدفة:**
>  1. **المتغير المدخل (Input):** اسم المتغير {lv=اسم المتغير} (لا توجد مشكله مع وجود المسافات في اسم المتغير).
>  2. **المتغير المخرج (Output):** اسم المتغير المستهدف ونوعه (نص String أو مصفوفة Array).
>  3. **شروط المحرك:** (تطبيق قيود JetPack Engine: لا تعليقات، لا رموز // مباشرة، استخدام var).
